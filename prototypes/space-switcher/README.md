# Prototype : bande d'espaces

Prototype jetable, pas branché sur le vrai moteur — le but est de sentir le
geste (bande persistante, sélection, dépôt d'un objet sur un espace pour
l'y déplacer), pas d'intégrer. Données bidon dans `src/App.svelte`.

Décision associée (`docs/spec.md`) : une bande persistante plutôt qu'un
menu radial pour l'accès aux espaces — « toujours accessible » et
« radial » sont deux propriétés différentes, le radial sert mieux la
sélection rapide d'un verbe sur un objet.

```
npm install
npm run dev
```
