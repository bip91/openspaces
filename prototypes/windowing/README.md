# Prototype : fenêtrage glissable

Prototype jetable, pas branché sur le vrai moteur — fenêtres déplaçables
(barre de titre) et redimensionnables (coin bas-droit), passage au premier
plan au clic. Données bidon dans `src/App.svelte`.

Teste aussi la question laissée ouverte en conversation : « Objets »,
« Liens », « Bus » (nos pages Django réelles) ouverts comme des fenêtres
séparées, qu'on peut (ré)ouvrir/fermer depuis le dock du bas, plutôt que
des pages qu'on quitte pour y aller — la première application concrète de
B9 (comparer sans basculer).

```
npm install
npm run dev
```
