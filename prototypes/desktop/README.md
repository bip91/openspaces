# Prototype : desktop (fusion)

Fusion des deux prototypes précédents (`space-switcher`, `windowing`),
toujours jetable et déconnecté du vrai moteur — le but est de voir les
gestes *ensemble*, pas chacun isolé.

- Bande d'espaces à gauche (clic pour changer, glisser une carte d'objet
  depuis la fenêtre « Objets » sur une bulle pour la déplacer).
- Fenêtres « Objets » (contenu dépendant de l'espace actif), « Liens »,
  « Bus » — déplaçables, redimensionnables, accrochables aux bords/4 coins
  avec aperçu.
- Dock en bas pour (ré)ouvrir/fermer chaque fenêtre.

```
npm install
npm run dev
```
